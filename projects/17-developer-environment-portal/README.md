# Build a Developer Environment Portal

![Developer Environment Portal](assets/project-cover.svg)

Build reproducible development environments with authentication, resource limits, expiration and AI-assisted setup diagnostics.

## What you will build

Create a working system with application components, an AI capability, automated delivery and operational visibility. Review access boundaries, test expected behaviour and investigate controlled failures.
