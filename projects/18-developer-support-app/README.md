# Build a Developer Support App

![Developer Support App](assets/project-cover.svg)

Build a support service with diagnostic evidence collection, request routing, document retrieval and evaluated AI triage.

## What you will build

Create a working system with application components, an AI capability, automated delivery and operational visibility. Review access boundaries, test expected behaviour and investigate controlled failures.
