# Build a Service Dependency Dashboard

![Service Dependency Dashboard](assets/project-cover.svg)

Build a dependency graph from service metadata and telemetry with AI-assisted change-impact explanations.

## What you will build

Create a working system with application components, an AI capability, automated delivery and operational visibility. Review access boundaries, test expected behaviour and investigate controlled failures.
